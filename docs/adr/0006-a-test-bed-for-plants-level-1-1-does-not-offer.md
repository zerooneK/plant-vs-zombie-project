# A test bed for plants Level 1-1 does not offer

A Wall-nut and a Tall-nut are built and checked, and Level 1-1's Seed Bank still offers a Peashooter and a Sunflower. The two plants are reachable through a **test bed** — a Level offering all four plants, at `dist/index.html?level=test-bed` — rather than through the level the game starts on.

*(Amended at ticket 12: the test bed's Seed Bank holds every plant the game has, so "all four" is now seven — the Snow Pea, Repeater and Puff-shroom joined them. The decision is unchanged; only the number in it grew, which is what a table of plants is for. Every plant the game does not sell in a real Level is reached this way, and the reason has not moved.)*

Level 1-1 stays as it is because the balance pass that comes next is meant to measure it as it is. `docs/adr/0005-sunflower-before-wall-nut.md` put that pass immediately after the Sunflower for the same reason it put the Sunflower before the Wall-nut: a schedule tuned before the thing exists is tuned against a lie. Adding a fourth packet to the Seed Bank changes what Level 1-1 asks of a player, and the ticket that is about to measure Level 1-1 should be measuring Level 1-1 and not a version of it with a Wall-nut in the bank. Which of these plants belongs in a Level, and at what point, is that pass's answer and not this ADR's.

A plant no Level offers is still a problem worth solving rather than sitting on. There are exactly two ways to reach one: a check that builds the Level it needs, and a person who wants to look at one. The first was never the difficulty — a check asks for whatever Level it wants, and `levelOffering` in `tests/helpers.ts` says which plants and which Zombies in one line. The difficulty is the second, and it is the one that was actually blocking. Every plant so far has had exactly one claim that no check could make, which is that it looks like itself: a Sunflower had to be a flower and not a green circle, or the Seed Bank is naming two pictures the player cannot tell apart. The two nuts have the same claim twice over, and they are told apart by shape alone, so it cannot be argued from a colour value. That answer is a screenshot of a real lawn with real plants on it, and there was no way to get one.

So the test bed exists to be looked at, and is built to be cheap to look at: all four plants in one Seed Bank, one Zombie in every Row, and nothing for forty-five seconds, which is as long as a Zombie takes to cross the whole lawn. It is a level anybody can poke at, and it is not a level anybody plays — it has no Flag Wave and its schedule is not balanced and does not claim to be.

**The address names a Level; it is not level select.** Nothing is unlocked, nothing is chosen from a menu, and `LEVEL_1_1` is still what the game starts on — level select is ticket 20 and is still ahead. All it does is let `?level=` name a Level, which is what a Level already is: the rules begin from one, and say which. An address naming a Level that does not exist gets the one the game starts on rather than a blank lawn, because a mistyped query string is a wrong request and the rules' own answer to a Level nobody defined is the first one.

**The rules are told nothing about it.** `levelFromTheAddress` is in `App.tsx`, it is read once before the game exists, and it cannot change anything while a level is being played. `LEVELS` is a table in `levels.ts` so that a Level cannot be added to the game without being findable by the thing that hands the game its Level — a Level is data, and adding one stays an edit.
