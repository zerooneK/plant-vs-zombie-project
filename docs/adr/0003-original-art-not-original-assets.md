# Draw our own simple art instead of using the original's assets

All artwork is original, simple flat SVG shapes made for this project. The original Plants vs. Zombies sprites, character names and audio are not used. The game rules and mechanics are what we are copying, and those are far more loosely protected than artwork, so this keeps the project shareable instead of making it a copyright problem. The characters are expected to change later anyway, so our own art makes that a swap rather than a rewrite.
